# Práctica: Catálogo de Productos con HTML y CSS

## Descripción del proyecto

Esta práctica consiste en desarrollar una página web que presenta un catálogo de productos mediante el uso de HTML y CSS. El objetivo es crear tarjetas visuales que permitan mostrar diferentes artículos de manera organizada, atractiva y sencilla.

## Objetivo

Aplicar los conocimientos básicos de HTML y CSS para diseñar una interfaz web que permita visualizar productos en forma de tarjetas.

## Tecnologías utilizadas

- **HTML5:** Para crear la estructura y organizar el contenido de la página.
- **CSS3:** Para aplicar estilos, colores, bordes, sombras, espacios y diseños a las tarjetas.

## Características

- Diseño de tarjetas individuales para cada producto.
- Imágenes representativas de los artículos.
- Nombre y descripción de cada producto.
- Presentación organizada en forma de catálogo.
- Uso de colores, bordes redondeados y sombras.
- Diseño visual limpio y atractivo.

## Estructura del proyecto

```text
Catalogo-de-Productos/
│
├── index.html
├── style.css
└── img/
    └── imagenes de los productos
```

## Aprendizajes obtenidos

Durante esta práctica se trabajó con la estructura básica de HTML, la aplicación de estilos mediante CSS, la organización de elementos utilizando tarjetas y la presentación de contenido en una página web.
